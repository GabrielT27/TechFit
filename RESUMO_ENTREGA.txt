🚀 COMO COMEÇAR EM 4 PASSOS
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Prepare o Ambiente
  └─ Instale XAMPP (Apache + PHP + MySQL)
  └─ Inicie Apache e MySQL

PASSO 2: Configure Banco de Dados
  └─ Copie a pasta TechFit para htdocs
  └─ Abra phpmyadmin
  └─ Crie banco: techfit_db
  └─ Importe: setup.sql

PASSO 3: Configure Conexão
  └─ Abra: config/Database.php
  └─ Ajuste: host, db_user, db_pass (se necessário)
  └─ Padrão: host=localhost, user=root, pass=''

PASSO 4: Teste e Use
  └─ Abra: http://localhost/TechFit/teste.php
  └─ Verifique se tudo OK (verde)
  └─ Acesse: http://localhost/TechFit/
  └─ Use o sistema!

💾 BANCO DE DADOS
═══════════════════════════════════════════════════════════════════════════════

TABELA: usuarios
  • ID (Int, PK)
  • Nome (Varchar 100, Not Null)
  • Email (Varchar 100, Unique, Not Null)
  • Telefone (Varchar 20, Not Null)
  • Endereco (Text, Not Null)
  • Data Cadastro (Timestamp)
  • Data Atualizacao (Timestamp)

TABELA: membros
  • ID (Int, PK)
  • Usuario ID (Int, FK)
  • Tipo Plano (Varchar 50, Not Null)
  • Data Inicio (Date, Not Null)
  • Data Fim (Date, Nullable)
  • Status (Varchar 20, Default 'ativo')
  • Data Cadastro (Timestamp)

TABELA: pagamentos
  • ID (Int, PK)
  • Membro ID (Int, FK)
  • Valor (Decimal 10.2, Not Null)
  • Data Pagamento (Date, Not Null)
  • Metodo Pagamento (Varchar 50, Not Null)
  • Status (Varchar 20, Default 'pago')
  • Descricao (Text, Nullable)
  • Data Cadastro (Timestamp)

🎯 ROTAS DISPONÍVEIS
═══════════════════════════════════════════════════════════════════════════════

BASE URL: http://localhost/TechFit/

DASHBOARD:
  GET  /                                  Página Inicial
  GET  ?module=dashboard                  Dashboard

USUÁRIOS:
  GET  ?module=usuarios                   Listar Usuários
  GET  ?module=usuarios&action=create     Criar Usuário (Form)
  POST ?module=usuarios&action=store      Salvar Usuário
  GET  ?module=usuarios&action=edit&id=1  Editar Usuário (Form)
  POST ?module=usuarios&action=update&id=1 Atualizar Usuário
  GET  ?module=usuarios&action=delete&id=1 Deletar Usuário

MEMBROS:
  GET  ?module=membros                    Listar Membros
  GET  ?module=membros&action=create      Criar Membro (Form)
  POST ?module=membros&action=store       Salvar Membro
  GET  ?module=membros&action=edit&id=1   Editar Membro (Form)
  POST ?module=membros&action=update&id=1 Atualizar Membro
  GET  ?module=membros&action=delete&id=1 Deletar Membro

PAGAMENTOS:
  GET  ?module=pagamentos                 Listar Pagamentos
  GET  ?module=pagamentos&action=create   Criar Pagamento (Form)
  POST ?module=pagamentos&action=store    Salvar Pagamento
  GET  ?module=pagamentos&action=edit&id=1 Editar Pagamento (Form)
  POST ?module=pagamentos&action=update&id=1 Atualizar Pagamento
  GET  ?module=pagamentos&action=delete&id=1 Deletar Pagamento
  GET  ?module=pagamentos&action=relatorio Relatório Financeiro
